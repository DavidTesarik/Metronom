# Zdroje a licence

Všechen kód, grafika i zvuky v této aplikaci jsou vlastní.

- **Písmo:** žádné stahované písmo. Aplikace používá systémové písmo zařízení
  (Avenir Next / Segoe UI / systémový bezpatkový font). Nic se nestahuje
  z Google Fonts ani odjinud.
- **Ikony v rozhraní:** znaky z Unicode (◴ ⛳ ▥ ⚙ × + −), žádná externí sada.
- **Ikona aplikace:** vlastní, vygenerovaná skriptem z geometrických tvarů.
- **Zvuky:** syntetizované za běhu přes Web Audio API (oscilátory a šum).
  Žádné nahrávky, žádné samply.
- **Knihovny:** žádné. Čisté HTML, CSS a JavaScript.

## Poznámka k názvu Tour Tempo

„Tour Tempo" je označení metodiky a knihy Johna Novosela a jeho ochranná známka.
Tato aplikace s jejími vlastníky nijak nesouvisí, není jimi schválená a
neobsahuje žádný jejich obsah. Poměry nápřahu k dopadu (3:1, 2:1) jsou
veřejně popsaná čísla; tóny v aplikaci jsou vlastní syntéza.
